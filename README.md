## How to compare AliExpress listings before applying a code

A promo code cannot fix a poor listing choice. Before adding an item to the cart, check:

### The exact model or variant

Many AliExpress pages advertise a low starting price for the smallest capacity, simplest configuration, or accessory-only version. Make sure the selected option is the product you intended to buy.

For electronics, compare storage, voltage, connector type, chipset, dimensions, and included accessories. For tools, check whether the price covers the tool itself, a replacement part, or only a compatible attachment.

### Shipping and warehouse

The same item may be offered from different warehouses with different delivery times and shipping fees. A lower product price can disappear once delivery is added.

For a time-sensitive purchase, the delivery estimate should matter more than a possible cashback reward. ShopBack’s own guidance recommends comparing the exact listing, seller, shipping, and return terms rather than relying on the product name alone.

### Seller history and reviews

Read the recent review photos when available. Review counts and star ratings are useful signals, but they do not replace checking the actual specification and variant. Marketplace listings can change their title, image, or selected default option over time.

### Return and dispute conditions

AliExpress support depends on the order, seller, item, and applicable buyer-protection process. Keep the order record, tracking information, photos, and packaging if a product arrives damaged or does not match the listing.

ShopBack excludes returned, refunded, cancelled, and rejected orders from cashback. A partial return can also lead to a cashback adjustment.

## Why an AliExpress code may fail

A code can fail for several ordinary reasons:

- The order does not meet the required minimum.
- The code is limited to another region.
- The campaign has ended or reached its allocation limit.
- The selected products are excluded.
- The coupon has already been used on the account.
- The cart total changes after shipping or variant selection.
- The code applies only to the merchandise subtotal.
- The checkout currency or delivery country does not match the campaign.
- Another promotion has already been applied.
- The code belongs to a different event, such as Choice Day rather than the monthly US campaign.

If the code fails, do not keep adding unrelated items simply to reach the threshold. Try the code that matches the cart’s current value, remove excluded products temporarily, and compare the final total with and without the promotion.
